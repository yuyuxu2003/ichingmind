## 1. Project Overview

### Project Name
**IChingMind**

### One-line Positioning
An English editorial-style content website that presents the *I Ching* as an ancient Eastern framework for understanding situations, change, timing, self-cultivation, and modern decision-making.

### Project Goal
Build a clean, elegant, SEO-friendly, static-first website for publishing original long-form essays in English.

This is **not** a fortune-telling website.  
It should feel:

- calm
- intelligent
- reflective
- minimal
- literary but modern
- culturally rooted but globally readable

### Version 1 Objectives
- Launch a visually strong English content site
- Publish and organize long-form essays
- Build trust and brand identity
- Be easy to maintain and update
- Be ready for future expansion:
  - newsletter
  - ebook
  - consultation
  - premium essays / course

---

### Core Idea
The *I Ching* should be presented not as superstition, but as:

- a language of situations
- a framework for reading change
- a philosophy of timing
- a reflective tool for decision-making
- a discipline of inner steadiness

### What This Site Is
- an editorial philosophy website
- a long-form essay publication
- a personal knowledge and reflection archive
- an East-meets-modern strategic wisdom project

### What This Site Is NOT
- not a fortune-telling platform
- not a mystical gimmick site
- not clickbait spirituality
- not an e-commerce-first product site
- not an academic-only translation archive

### Preferred Language Style

- strategic wisdom

- decision

Avoid overusing:
- destiny
